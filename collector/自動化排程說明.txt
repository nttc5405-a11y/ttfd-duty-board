勤務看板採集器 — 全自動排程設定說明
============================================================

目的：讓「開啟頁面 + 觸發採集」這件事每天固定時間自動發生，
不需要每天早上手動點書籤。

重要界線（沒有改變）：這套自動化**不會、也不能自動登入**。
它能做的是「如果瀏覽器的登入狀態還活著，自動把採集流程接起來」；
如果登入狀態已經過期，Chrome 視窗會停在登入畫面，安靜等待，
不會有任何資料被送出，需要有人手動登入一次。

============================================================
第一部分：安裝 Tampermonkey 腳本（一次性設定）
============================================================

前提：確認你已經用書籤版（collector-bookmarklet.txt）成功執行過
至少一次，且看板伺服器網址與通行碼已經記在這台電腦的瀏覽器裡
（狀態視窗第一行有顯示「看板伺服器：https://...」代表已經記住）。
沒有這個前提，自動模式會直接顯示錯誤、不會啟動。

1. 安裝 Tampermonkey 擴充功能：
   https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo
   點「加到 Chrome」

1.5 【重要，容易漏掉的一步】開啟 chrome://extensions，找到
   Tampermonkey → 點「詳細資料」，往下捲找到「**允許使用者指令碼**」
   這個開關，打開它。這是 Chrome 對「會執行使用者自訂程式碼」類
   擴充功能加的一道額外開關，沒開的話 Tampermonkey 裝了、腳本存了、
   一切設定看起來都對，但頁面上完全不會觸發，圖示也不會出現數字，
   很容易誤以為是腳本本身有問題（我們就在這裡卡過一次）。

2. 點瀏覽器右上角新出現的 Tampermonkey 圖示（一個黑白拼圖狀圖案）
   → 選「建立新指令碼」（或「Create a new script」）

3. 會打開一個編輯畫面，裡面已經有一小段預設內容，**全部刪掉**

4. 打開同資料夾的 collector.user.js，全選、複製，貼進剛才那個
   編輯畫面（貼上前先把畫面上原本的預設內容全部刪乾淨，見上一步）

4.5 貼上後，**務必檢查最上面 `// @match` 那一行**，要跟這裡完全一樣：
   // @match        https://ttfd2.firemis.tw/*
   原因：Tampermonkey「建立新指令碼」時，會自動把你當時開著的分頁
   網址帶入 @match 當預設值（例如變成
   `ttfd2.firemis.tw/#/shift/list`），如果貼上時沒有整段蓋掉、
   殘留了這個自動帶入的版本，腳本會存起來、開關也顯示打開，但實際
   上不會在任何頁面觸發（我們就在這裡卡過一次）。

5. 按左上角的儲存圖示（或 Ctrl+S）

6. 確認腳本已啟用：回到 Tampermonkey 的管理頁面（點圖示 →
   「管理面板」），應該會看到「勤務看板自動採集器」這一條，
   最左邊的開關要是打開（藍色）的狀態

============================================================
第二部分：先手動測試一次
============================================================

1. 確認已登入 ttfd2
2. 開一個新分頁，網址列輸入 ttfd2.firemis.tw/#/shift/list，Enter
3. 頁面載入完成後，右下角應該會自動跳出「勤務看板採集器（自動
   模式）」的狀態視窗，不用點任何東西
4. 看到「完成 ... 單位 6 個、勤務 N 項」代表運作正常

如果沒有跳出視窗，先檢查 Tampermonkey 圖示上有沒有顯示數字
（代表這個網址有腳本在跑），沒有的話回頭檢查 @match 那行網址
是否跟你瀏覽器網址列的網址一致。

============================================================
第三部分：設定 Windows 排程器，每天自動開啟頁面
============================================================

這一步只負責「每天固定時間開一個 Chrome 分頁到 ttfd2」，
實際抓資料的動作由上面裝好的 Tampermonkey 腳本自動接手。

1. 按 Windows 鍵，打字「工作排程器」（Task Scheduler），開啟它

2. 右側面板點「建立基本工作...」

3. 名稱填「勤務看板每日更新」，下一步

4. 觸發程序選「每天」，下一步，設定時間（建議 07:15，比採集器
   內建的 07:00 排程晚一點，確保頁面真的開好了）

5. 動作選「啟動程式」，下一步

6. 「程式或指令碼」欄位貼：
   C:\Program Files\Google\Chrome\Application\chrome.exe

   「新增引數」欄位貼：
   https://ttfd2.firemis.tw/#/shift/list

7. 下一步，勾選「完成時開啟這個工作的內容對話方塊」，按「完成」

8. 跳出的內容對話方塊裡：
   - 「一般」分頁：確認「不論使用者是否登入均執行」**不要**勾選
     （要維持勾選「只有使用者登入時才執行」，因為要開啟畫面，
     必須有人已經登入 Windows 桌面）
   - 「條件」分頁：把「只有在電腦使用交流電源時才啟動此工作」
     取消勾選（筆電才需要在意，桌機不影響）
   - 按確定

完成後，每天設定的時間，Windows 會自動開一個 Chrome 分頁到
ttfd2 勤務表列表頁；如果那時候登入狀態還活著，Tampermonkey 腳本
會自動接手，不需要任何人動手。

============================================================
第四部分：怎麼確認有沒有正常運作
============================================================

- 最直接：隔天早上看那個自動開啟的 Chrome 分頁，右下角狀態視窗
  應該已經跑過至少一次「完成」
- 如果分頁停在登入畫面：代表登入狀態過期了，需要手動登入一次，
  這是預期內、需要人工介入的唯一情況
- 也可以直接看看板本身，或用瀏覽器開
  你的看板網址/api/health
  確認 receivedAt 的時間是不是接近排程設定的時間

============================================================
常見問題
============================================================

Q：這樣是不是就完全不用管了？
A：不是。這套解決的是「重新整理頁面 + 觸發採集」這個動作，
   前提是登入狀態還活著。系統遲早會把你登出（時間長短因系統
   設定而異），那時候還是需要有人登入一次。這套自動化把「每天
   手動點一次書籤」降低成「登入狀態過期時才需要手動處理」，
   不是完全零維護。

Q：Windows 排程器那台電腦需要一直開著嗎？
A：需要，而且要有人登入 Windows 桌面（不能只是插著電但沒登入
   使用者），因為要能顯示 Chrome 視窗。適合裝在隊部值班室那種
   本來就整天有人、電腦不太關機的地方。

Q：可以同時保留手動點書籤的方式嗎？
A：可以，兩者不衝突。書籤版跟 Tampermonkey 版本邏輯完全一樣，
   平常想立刻更新一次，一樣可以手動點書籤。
