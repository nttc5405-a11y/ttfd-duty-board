授權存放位置探測（第四階段）— 書籤版
============================================================

目的：採集器在 localStorage / sessionStorage 裡找不到登入授權，
      這支列出瀏覽器實際存了什麼（只列鍵名與型別，敏感值會遮蔽），
      藉此找出正確的存放位置。

【怎麼裝】
Ctrl+Shift+O →「⋮」→ 加入新書籤，名稱填：探測授權
網址欄貼底下那一整行

【怎麼用】— 一次即可
1. 確認已登入 ttfd2，停在任一頁面
2. 點一下「探測授權」書籤
3. 右下角出現結果框，內容已自動全選 → Ctrl+C 複製，貼回對話
4. 雙擊框可關閉

【它做什麼】
列出 localStorage、sessionStorage、Cookie 各有哪些鍵名，
以及每個值的「長度與開頭幾個字元」（不是完整內容，避免外洩實際權杖）。
含 token / auth / jwt / session / key 等關鍵字的鍵名會特別標記。
不會送出任何資料，只顯示在你自己的螢幕上。
