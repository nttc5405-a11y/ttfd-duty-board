勤務表細部結構探測（第三階段，最後一支）— 書籤版
============================================================

目的：看清楚 tables 裡每小時的 {value, index} 到底裝什麼，
      以及系統呼叫 API 時帶了哪些認證標頭。
      知道這兩件事，採集器就寫得出來了。

【怎麼裝】
Ctrl+Shift+O →「⋮」→ 加入新書籤，名稱填：探測細表
網址欄貼底下那一整行

【怎麼用】— 一樣點兩次
1. 在勤務表列表頁，點第一次「探測細表」→ 跳出「已安裝」提示
2. 點進「成功分隊」的勤務表（一定要點進分隊，不是停在列表頁）
3. 點第二次「探測細表」→ 結果框出現 → Ctrl+C 貼回對話
4. 雙擊框可關閉

【它做什麼】
只攔截系統自己發出的請求，把勤務表的欄位定義與前兩位人員的
前幾個小時完整印出來，用來對照畫面驗證解讀是否正確。

安全設計：
  - 認證標頭（Authorization / Token / Cookie）一律顯示 ***，只列出標頭名稱
  - 不主動呼叫任何 API，不送出任何資料
  - 重新整理頁面後即消失
