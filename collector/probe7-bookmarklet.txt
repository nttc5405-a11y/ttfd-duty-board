單位狀態 API 直接查詢探測（第七階段）— 書籤版
============================================================

跟第六支不同：這支不用等頁面自己重新發請求，而是沿用「點查詢時
攔截授權」的既有做法（跟採集器一樣），拿到授權後直接主動打
shift-status/list 與 shift-record/list 這兩支 API，把完整回應
顯示出來。只要能點一次「查詢」，一次就能看到結果，不用碰運氣等
畫面自動刷新。

安全設計：只打這兩支網址（低風險的單位狀態資料），不會呼叫任何
含 /case/ 的網址；授權值只存在這次執行的記憶體裡，不落地存檔。

【怎麼裝】
Ctrl+Shift+O 開書籤管理員 →「⋮」→ 加入新書籤，名稱填：探測單位狀態2
網址欄貼底下那一整行

【怎麼用】— 一次即可，但要在「勤務表列表」頁執行（不是案件系統首頁）
1. 登入 ttfd2.firemis.tw，開到「勤務表列表」頁
2. 點一下「探測單位狀態2」書籤
3. 它會自動幫你點一次「查詢」取得授權，接著主動查詢兩支 API
4. 右下角出現結果框，內容已自動全選 → Ctrl+C 複製貼回對話
5. 若第一次沒抓到授權，畫面會提示手動按一次「查詢」，再點一次書籤即可
6. 雙擊框可關閉
