勤務系統 API 格式探測（第二階段）— 書籤版
============================================================

【怎麼裝】
同上一支：Ctrl+Shift+O 開書籤管理員 →「⋮」→ 加入新書籤
名稱填：探測API
網址欄貼底下那一整行（javascript: 開頭）

【怎麼用】— 這支要點兩次
1. 在勤務表列表頁，點第一次「探測API」書籤
   → 跳出提示視窗「攔截器已安裝」，按確定
2. 按一次頁面上的「查詢」按鈕
   （若還想抓分隊勤務表的格式，接著再點進任一個分隊）
3. 點第二次「探測API」書籤
   → 右下角出現結果框，內容已自動全選 → Ctrl+C 複製，貼回對話
4. 看完在框上雙擊即可關閉

【它做什麼】
不主動呼叫任何 API，只是「在旁邊看」系統自己發出的請求，
記下請求網址、送出的參數、以及回應的「欄位結構」。

安全設計：
  - 只記欄位名稱與型別，內容值一律截短到 20 字
  - 欄位名含 token / jwt / auth / password / secret 者，值顯示 ***
  - 結果只出現在你自己的螢幕，不傳送到任何地方
  - 重新整理頁面後攔截器自動消失，不會常駐

完整可讀版（含中文註解）在同資料夾的 probe2.js，內容與底下這行一致。
