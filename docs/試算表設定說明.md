# 試算表設定說明（密碼保護、單位代碼對照、跑馬燈公告、行事曆來源）

四個功能都改用 Google 試算表管理，改完試算表內容，看板最晚 30 分鐘內
自動生效（也可以手動立刻生效，見下方），不用改程式碼、不用重新部署。

**安全等級說明**：試算表本身維持私人（只有你自己看得到、可以編輯），伺服器
讀取靠「發布到網路」功能各自產生一個唯讀 CSV 連結——這個連結任何人拿到都
能讀到內容，但試算表本身的編輯權限完全不受影響，還是只有你能改。密碼、
單位代碼、跑馬燈這三個功能的機密程度都很低（密碼只是防手滑，不是真正
資料隔離，見文末說明），所以用這個簡單、不需要申請 Google Cloud 帳號的
做法就夠了；行事曆網址的機密程度較高（等同密碼），但因為原本
`CAL_ICS_URL_*` 環境變數就是用同一種「網址即通行證」的模式，這裡延續
同樣的信任等級，沒有降低現有安全性。

---

## 一、建立試算表與三個分頁

1. 到 Google 試算表建立一份新檔案，取名例如「勤務看板設定」。
2. 建立三個分頁（畫面下方分頁籤），**欄位名稱要完全比照下列打**（打錯欄名，
   那一整欄會被忽略，看板會照「沒設定」處理，不會報錯也不會提示你打錯字，
   所以建議直接複製下面的表頭文字，不要手動重打）。

### 分頁一：密碼

| 大隊 | 密碼 |
|---|---|
| 管理員 | （你自己的主控密碼，填了可以解鎖全部大隊） |
| 台東大隊 | （自訂密碼） |
| 關山大隊 | （自訂密碼） |
| 大武大隊 | （自訂密碼） |
| 局本部 | （自訂密碼） |

「成功大隊」固定不設防（看板預設視角，不需要密碼，就算在這裡加一列也會
被忽略）；沒有列在這個分頁的大隊，切換時也不會被要求密碼。

### 分頁三：跑馬燈

| 公告文字 | 顯示大隊 | 啟用 |
|---|---|---|
| 範例：颱風警戒，明日停止一般收件 | 全部 | FALSE |

- 「顯示大隊」填「全部」表示所有大隊視角都看得到；也可以只填一個大隊
  名稱，或用頓號分隔多個，例如「台東大隊、關山大隊」。
- 「啟用」填 `TRUE` 才會顯示，`FALSE` 或空白都不會顯示——之後想暫時收回
  某則公告，改這一欄最快，不用刪除整列（保留紀錄，要恢復直接改回 TRUE）。
- 同時有多則啟用中且符合目前大隊視角的公告，會依序接在一起顯示。

### 分頁四：行事曆

讓各單位自己上傳自己的 Google 行事曆訂閱網址，切換大隊視角時，行事曆
面板只會顯示該大隊自己上傳的內容（篩選鈕也會跟著換成該大隊自己的來源
名稱），不會看到別的大隊的行程。

| 名稱 | 所屬大隊 | 網址 |
|---|---|---|
| 大隊 | 台東大隊 | （台東大隊自己的行事曆網址） |
| 義消 | 關山大隊 | （關山大隊義消的行事曆網址） |

- 「名稱」是這個來源要顯示的標籤（例如「大隊」「義消」），同一個大隊
  底下可以有好幾列，各自標不同名稱；不同大隊也可以各自取一個一樣叫
  「大隊」的名稱，不會互相干擾，因為篩選是先依「所屬大隊」分開的。
- **這個分頁是跟 Render 環境變數 `CAL_ICS_URL_DAJI`／
  `CAL_ICS_URL_YIXIAO`／`CAL_ICS_URL_JUBENBU`「疊加」在一起，不是
  取代**——成功大隊現有的行事曆繼續用那三個環境變數就好，**不用**
  搬進這個分頁；這個分頁只用來新增「其他大隊」自己的行事曆來源。
  請不要在這個分頁裡也填一列「成功大隊」，否則會跟環境變數的來源
  重複顯示兩次。
- **重要的隱私提醒**：行事曆的 iCal 訂閱網址等同密碼，知道網址的人
  就能讀到該行事曆的內容。這個分頁發布成網路連結後，內容技術上任何
  人拿到連結都讀得到（雖然網址很長很難猜到）——這跟環境變數（只有
  你在 Render 後台看得到）比起來，曝險程度略高。建議：
  - 如果該大隊的行事曆本身就設成公開的（例如公告類、不涉及個資），
    直接用「公開網址」放進這個分頁最單純。
  - 如果該大隊的行事曆內容比較敏感、想要跟成功大隊一樣用環境變數等級
    的保護，跟我說一聲，我幫你多加一組專屬環境變數即可，一樣不用
    改程式碼。
- 還沒上傳行事曆的大隊，切過去會看到「所選的行事曆來源近期無行程」，
  不是壞掉，是還沒有資料。

## 二、把每個分頁發布成網路連結

對每一個分頁重複以下步驟（有填內容的分頁要**各自發布一次**，會拿到不同
網址，不要搞混）：

1. 點開該分頁的分頁籤（畫面最下方），確認目前顯示的是你要發布的那一頁。
2. 上方選單：**檔案 → 共用 → 發布到網路**。
3. 跳出視窗左邊下拉選單，選成該分頁的名稱（不要選「整份文件」）。
4. 右邊下拉選單選「**逗號分隔值檔案 (.csv)**」。
5. 按「發布」，跳出確認視窗按「確定」。
6. 複製跳出來的網址，記下這是哪個分頁的（例如檔名記成
   `密碼-網址.txt`、`單位代碼-網址.txt`……方便自己對照）。

## 三、把網址設定進 Render

把發布出來的網址交給我（或你自己動手），設定進 Render 服務的 Environment：

- `CONFIG_PASSWORDS_URL`：密碼分頁的網址
- `CONFIG_DEPTS_URL`：單位代碼分頁的網址
- `CONFIG_CALENDARS_URL`：行事曆分頁的網址
- `CONFIG_NOTICES_URL`：跑馬燈分頁的網址

四個都是選填、互相獨立——只設定其中幾個也可以，沒設定的功能就不會
生效，不影響看板其餘功能。設定好、Render 重新部署後即生效。

## 四、之後怎麼用

- **改密碼／跑馬燈**：直接改對應分頁的儲存格，最晚 30 分鐘內全站自動
  生效；想立刻生效，瀏覽器開
  `https://你的網址/api/config-refresh?token=你的PUSH_TOKEN`
  （PUSH_TOKEN 跟採集器用的是同一組）。
- **新增或改編單位**：先查出新單位的「單位代碼」（見下一節），在
  「單位代碼」分頁新增一列，填代碼、名稱、所屬大隊即可。
- **新增某個大隊的行事曆**：在「行事曆」分頁新增一列，填名稱、所屬
  大隊、網址即可；行事曆本身不是每 30 分鐘自動抓（那個排程只更新
  「有哪些來源」這份清單），實際內容一樣是每 12 小時自動排程讀取，
  想立刻生效可以瀏覽器開
  `https://你的網址/api/cal-refresh?token=你的PUSH_TOKEN`。

## 五、如何查詢單位代碼

新增或改編單位時，需要先知道它的「單位代碼」（dept ID）才能填進「單位
代碼」分頁。查詢方法是重複使用之前探測全縣單位時做的書籤工具，不用另外
安裝新工具：

1. 用看得到該單位的帳號（通常是局本部帳號）登入 ttfd2.firemis.tw，開到
   「勤務表列表」頁。
2. 確認畫面上的單位篩選欄清空或選「全部」，讓表格盡量顯示出全部單位。
3. 點一下「探測全縣單位ID」書籤（安裝方式見
   `collector/probe8-dept-ids-bookmarklet.txt` 檔頭的說明）。
4. 右下角會跳出一個文字框，內容類似：
   ```
   dept=593f82a5a326a612c81cfc99  主管=大隊長王小明  =>  台東大隊
   ```
   等號左邊 `dept=` 後面那一長串英數字就是單位代碼，箭頭右邊是對應的
   單位名稱。
5. 把新單位那一行的代碼複製起來，填進「單位代碼」分頁對應欄位。

## 安全性提醒

密碼保護只是「防手滑切到別的大隊」的軟性提醒，**不是真正的資料隔離**——
伺服器本來就會把全縣資料一起送到瀏覽器（不然大隊選單、成功大隊借用全縣
資料這些既有功能都無法運作），密碼只是讓畫面不去渲染出來而已。真的想看，
打開瀏覽器開發者工具的「網路」分頁還是看得到全部內容。這個保護等級跟看板
其他資料本來就一致（整個看板都沒有登入機制），如果之後想要更嚴格、真正
依權限隔離資料的保護，需要另外設計伺服器端驗證機制，工程量會大幅增加，
屆時可以再討論。
